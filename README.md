Student-Course Management System 

## About the Project

This is a Python project I created to practise and understand Object-Oriented Programming (OOP). The system manages student information and courses, allowing users to view records and search for specific students or courses.

## What Can It Do?

* Store student and course information.
* Display student details and the courses they take.
* Display information about available courses.
* Search for a student using their student ID.
* Search for a course using its course code.
* Show a message when a student or course cannot be found.

## What I Used

* Python
* Classes and objects
* Methods and functions
* Lists
* GitHub

## Project File

* `Programming_Assignment1.py` — contains the main code for the project.

## What I Learned

While working on this project, I practised creating classes and objects, working with lists, writing functions, and using search conditions to find records. I also learned how to use Git and GitHub to upload and manage my code.

## Running the Project

1. Make sure Python 3 is installed.
2. Download the project file.
3. Open it in PyCharm or another Python editor.
4. Run `Programming_Assignment1.py`.
